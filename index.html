Owner-operated desktop integration

A small, private bridge to Google Drive.

Netherbrain KC Bridge is a personal desktop workflow that helps its owner transfer selected project reports and manifests between a local Kali Linux computer and the owner's Google Drive using rclone and Google OAuth.

Read the privacy policy Terms of use

How the integration works

1. Owner authorizes access

The owner signs in through Google's OAuth consent flow on the local device. This site does not handle sign-in or receive OAuth tokens.

2. Limited Drive scope

The integration requests the drive.file scope, limited to files created or opened with the application, rather than unrestricted access to all Drive files.

3. Private files stay private

Selected technical artifacts are transferred into the owner's private Drive storage. This public website does not publish or display those files.

About this website

This is an informational website for a private, owner-supervised development tool. It is not a public file-sharing service, does not accept uploads, and does not provide a public API or account registration.
