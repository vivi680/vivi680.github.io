Privacy & Google user data

Privacy Policy

Effective: 6 November 2026

Netherbrain KC Bridge (the “application”) is an owner-operated desktop workflow for transferring selected technical reports, manifests and related files between a local computer and the owner's Google Drive. This website explains the application; it is not an online application and does not receive the owner's Drive data.

1. What Google data the application accesses

The application uses Google OAuth with the Google Drive drive.file scope. It accesses the content and metadata (such as names and folder locations) of files created or opened with the application. It does not request unrestricted access to all Google Drive files, Gmail, contacts or calendar data.

2. How the data is used

Google Drive access is used to upload, read, list and manage explicitly selected project files within the owner's authorized Drive workspace. The owner may separately choose to review selected files through a separately authorized ChatGPT/Google Drive connection; that is not an automatic transfer by this website.

3. Storage and credentials

Transferred documents are stored in the owner's Google Drive. OAuth tokens are handled by rclone on the owner's local device and are not embedded in this website or published in the website's source repository. This informational site has no account registration, forms, upload mechanism or application database.

4. Sharing and third parties

The application is not designed to sell Google user data, use it for advertising or share it with unrelated parties. Google provides the OAuth and Drive services. GitHub hosts this public informational website and may process ordinary web-access logs under its own policies. Any separate decision by the owner to share a file with an authorized review tool or collaborator occurs outside this website.

5. Retention, deletion and revocation

The owner controls retention and deletion of transferred files in Google Drive and of local files on their computer. The owner can revoke the application's OAuth access in Google Account settings at any time. Revocation stops future authorized API access but does not itself delete files already stored in Drive or local copies.

6. This public website

The website contains static informational pages and does not include advertising, analytics scripts or application-set tracking cookies. It does not collect Google Drive file content or OAuth credentials.

7. Contact and changes

Questions about this policy can be raised through the public GitHub issue tracker. Policy changes will be published here with an updated effective date before any materially different data use is introduced.

Resumen en español

KC Bridge es una herramienta personal ejecutada en el portátil del propietario. Solicita únicamente el permiso drive.file para los archivos seleccionados o creados con la aplicación. Los documentos se guardan en el Google Drive del propietario; los tokens OAuth permanecen en la configuración local de rclone. Esta web pública no recibe archivos ni credenciales. El propietario puede revocar el acceso y gestionar la eliminación de sus archivos.
